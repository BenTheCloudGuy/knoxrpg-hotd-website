# Question & Answer Mode

**Confidence:** high

## Pattern

When a prompt starts with `??`, answer the question without making any changes to the project or files.

### Rules

- **Code / Configuration / Documentation questions:** Provide a clear, concise answer. If ambiguous, ask for clarification. Provide references to relevant docs.
- **Campaign questions:** Review all relevant campaign data using DM AI tools. Provide a comprehensive answer based on campaign context.
- **File / Code snippet questions:** Review the relevant files and synthesize an answer from all necessary content.
- **Error / Issue questions:** Review error messages, logs, and diagnostics. Provide root cause analysis and actionable resolution steps.

### Always

- Show reasoning process and assumptions in your output
- Be accurate, relevant, and helpful
- Ask for clarification if unsure about any aspect
- Do NOT make any changes to files unless explicitly asked

## Learned from

- Q&A workflow used throughout campaign development
